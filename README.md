# 便签提醒 RemindNotes

桌面便签 + 到点弹窗提醒。常驻托盘，到点弹一个居中的窗口。

## 启动

双击 `RemindNotes.exe` 就能用（免安装、不需要 Python）。关掉窗口只是收起来，程序继续在托盘运行

## 三种提醒

| 类型 | 什么时候弹窗 |
|---|---|
| 单次 | 指定的日期时间弹一次窗 |
| 每天 | 每天固定时刻弹窗 |
| 循环 | 在指定的星期 / 工作日（或指定的日期区间）里，按时段每隔 N 分钟弹一次窗 |

循环还带这几项：

- **时段**（如 08:00–18:00）+ **间隔**（如每 60 分钟）
- **计时**二选一：
  - *固定时刻* —— 从时段起点按格子排、到点就弹窗。**时段起点那一格本身不弹**：起点只当锚点，第一声在「起点 + 一个间隔」（09:00 起的时段、每 60 分 → 10:00、11:00…）
  - *处理后计时* —— 从**你处理这一格的时刻**起算（14:00 弹、14:05 点「知道了」→ 下次 15:05）。弹窗上点「知道了」或「关闭」都算处理；**没处理的格子按原定时刻继续往前推**（14:00 弹了没人理 → 15:00 照弹一次、旧弹窗被新的顶掉），所以漏看不会让这条循环哑掉。跨天顺延到次日「时段起点 + 间隔」那一格（被顶掉、当时不在电脑前的那一格，事后也能在编辑框里点「已处理」补记 —— 见下面《漏看了那张弹窗》）

    重启时：还没到点的原样保留；已经过点的**不补弹** —— 同一天就接着自己原来的格子（存 12:10、12:30 启动 → 13:10），隔了一天则回到今天的「时段起点 + 间隔」（→ 10:00）

    编辑保存时：只改文案或「留记录」开关**不会动**下一次的时间；改了间隔/时段/星期/日期区间/计时方式才按**点保存那一刻**重新计时重排（不是打开编辑框那一刻）
- **包含结束时刻** —— 时段末尾那个点也弹窗
- **每次触发留一条记录** —— 默认关，开了列表里会有记录（见下）
- **工作日** —— 跟随国家法定节假日（含调休）：调休上班的周六照样弹窗，春节国庆放假的工作日不弹窗

### 「工作日」的数据从哪来

内置一份 2026 年的放假安排（随程序走）。之后的数据会自动更新，**平时不联网**：
只有当现有数据快用完（剩余不足 45 天）才会去拉一次，且一周最多试一次。
更新完就断网也能正常用 —— 数据落在磁盘上。

如果某年数据没跟上（你看到编辑框里「数据到 XXXX-XX-XX」已经过期），
工作日会退回成"周一至周五"：放假的周中不会白弹，但那一年的调休上班日
（通常是拿某个周六换来的）也认不出来 —— 那几天会漏。所以数据还是越新越好。

### 想自己加一天假 / 调休

国家安排管不着的个人例外（公司提前放假、你请了年假），写在：

    %APPDATA%\RemindNotes\holidays.local.json

内容就十来行，`holidays` 是放假、`makeup_workdays` 是上班：

```json
{
  "holidays": ["2026-10-10"],
  "makeup_workdays": ["2026-10-01"]
}
```

意思是：10-10 全国调休要上班，但我休息；10-01 全国放假，但我要上班。
**这个文件程序永远不会动**，自动更新不会把它冲掉。

### 作息不是跟随法定怎么办

- 固定作息（单休、双休、休周三…）：直接用「按星期」勾一~六，不需要新功能
- 大小周这种交替作息：暂时得靠上面那个手写文件，把单休周的那些周六写进
  `makeup_workdays`。麻烦，但不动程序

### 漏看了那张弹窗

双击便签本里一行、编辑一条「处理后计时」的循环时，页脚会多出一个 **「已处理」** 按钮
（`已处理 | 取消 | 保存`）。它就是替你补按一次弹窗上的「知道了」：**从你点它的这一刻**
重新计时 —— 10:43 点，下一次 11:43。

- **只在**编辑一条已有的、计时方式为「处理后计时」的循环时出现。新建、单次/每天、
  「固定时刻」的循环都没有 —— 新建本来就是"保存时刻 + 间隔"，固定时刻的格子也不由处理决定
- 点它会**先把表单里当前的内容一并保存**（顺手改了间隔、时段也一起生效）；校验不过就
  停在原地、什么都不改
- 那条循环若正挂着弹窗，会连带把弹窗关掉 —— 否则回头再点一下它的「知道了」会又推一格，
  等于推了两次
- 便签本里那条循环本身**不会**被标成已读；开了「每次触发留一条记录」才会多一条
  已完成记录，没开就只重排时间

## 托盘右键

| 菜单项 | 作用 |
|---|---|
| 打开便签本 | 显示主窗口（双击托盘图标也行） |
| 新建提醒 | 打开编辑框 |
| 开机自启 | 开机后静默进托盘 |
| 护眼模式 | 把近白纸换成米黄稿纸（勾选 = 已开） |
| 退出 | 真的退出程序 |

「护眼模式」压的是纸的亮度，不是往屏幕上加绿 —— 开了之后便签本、编辑框、新弹出的
提醒窗口都换成米黄稿纸。选过的状态会记住，下次启动照旧。

## 到点弹窗

居中弹出，**没有声音、不会闪烁**。三个按钮：

| 按钮 | 作用 |
|---|---|
| 知道了 | 标为已处理。循环的*处理后计时*从点它的这一刻重新起算 |
| 稍后 10 分钟 | 10 分钟后再弹一次（**不算处理**，不改变节奏） |
| 关闭 | 关掉窗口。循环的*处理后计时*同样从这一刻重新起算；单次便签上**不算已处理**，列表里仍会标红 |

同一时刻只留一个弹窗，后弹的覆盖前一个。

它在**任务栏里有自己的一格**：被别的窗口压住时，点一下就把它叫回最前；也可以直接把它最小化。

## 便签本

按钮有 新建 / 编辑 / 删除 / 标记已读，**双击一行**也能编辑。
多选按 Ctrl 或 Shift，**Ctrl+A 全选**。

「标记已读」只是清理列表，**不改变循环的节奏** —— 它不等于"处理了那张弹窗"，
所以循环的下一次不会因为你在列表里点了它而改期。要在列表这边补一次"处理了"，
请双击打开编辑框点 **「已处理」**（只对「处理后计时」的循环有，见上面那节）。

| 状态 | 含义 |
|---|---|
| 待提醒 | 还没到点 |
| 已错过 | 单次便签时间过了但没标记已读（**红色**） |
| 已完成 | 已标记已读 |
| 已结束 | 循环的日期区间已经走完 |

列表按状态分组：已错过 → 待提醒 → 已完成 → 已结束；组内按便签本来的时间点排（已错过和已完成是最近的在上，待提醒是马上要弹窗的在上）。

内容太长会截断并补「…」，换行会折成空格 —— 想看全文就拖表头边界把列拉宽，或双击打开编辑框。

**循环刷出来的记录会自动收起来**：开了「留记录」的循环每弹一次窗就补一条已完成记录，这些记录按来源收成一条可展开的条目（默认合上），免得把列表淹掉。

```
待提醒
  喝水提醒        循环   待提醒     ← 循环便签自己，照常显示
已完成
▸ 喝水提醒        记录   3 条       ← 它刷出来的记录收在这儿
```

- 点展开按钮或双击条目标题即可展开／收起
- 选中条目标题点「删除」= 删掉它名下那堆记录；展开后选中某条删 = 只删那一条
- Ctrl+A 全选会跳过条目标题，合着的条目里的记录照样选得上

底部那行时间**点一下**可以在「北京时间」和「本地时间」之间切换，选过会记住。

## 几点注意

- **错过的提醒不会补弹**：程序没运行时到了点的，只在列表里标红，不会下次启动一股脑弹出来。
- 便签存在 `%APPDATA%\RemindNotes\reminders.json`，每次改动立即落盘；文件坏了会自动改名成 `.bad` 并空着启动，不会崩。
