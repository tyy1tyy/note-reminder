# 便签提醒 RemindNotes

桌面便签 + 到点弹窗提醒。常驻托盘，到点弹一个居中的窗口。

## 启动

双击 `RemindNotes.exe` 就能用（免安装、不需要 Python）。关掉窗口只是收起来，程序继续在托盘运行

## 三种提醒

| 类型 | 什么时候响 |
|---|---|
| 单次 | 指定的日期时间响一次 |
| 每天 | 每天固定时刻响 |
| 循环 | 在指定的星期（或日期区间）里，按时段每隔 N 分钟响一次 |

循环还带这几项：

- **时段**（如 08:00–18:00）+ **间隔**（如每 60 分钟）
- **计时**二选一：
  - *固定时刻* —— 9:00、10:00、11:00… 到点就响
  - *处理后再计时* —— 从你点掉弹窗那一刻起算（9:20 点的，下次就是 10:20）。**没人点就一直等着**，不会自己往下走
- **包含结束时刻** —— 时段末尾那个点也响
- **每次触发留一条记录** —— 默认关，开了列表里会有记录（见下）

## 托盘右键

| 菜单项 | 作用 |
|---|---|
| 打开便签本 | 显示主窗口（双击托盘图标也行） |
| 新建提醒 | 打开编辑框 |
| 开机自启 | 开机后静默进托盘 |
| 退出 | 真的退出程序 |

## 到点弹窗

居中弹出，**没有声音、不会闪烁**。三个按钮：

| 按钮 | 作用 |
|---|---|
| 知道了 | 标为已处理 |
| 稍后 10 分钟 | 10 分钟后再响一次 |
| 关闭 | 只关窗口，**不算已处理**，列表里仍会标红。*例外*：「处理后再计时」的循环里，关闭也算一次处理 |

同一时刻只留一个弹窗，后弹的覆盖前一个。

## 便签本

按钮有 新建 / 编辑 / 删除 / 标记已读，**双击一行**也能编辑。
多选按 Ctrl 或 Shift，**Ctrl+A 全选**。

| 状态 | 含义 |
|---|---|
| 待提醒 | 还没到点 |
| 已错过 | 单次便签时间过了但没标记已读（**红色**） |
| 已完成 | 已标记已读 |
| 已结束 | 循环的日期区间已经走完 |

列表按状态分组：已错过 → 待提醒 → 已完成 → 已结束；组内按便签本来的时间点排（已错过和已完成是最近的在上，待提醒是马上要响的在上）。

内容太长会截断并补「…」，换行会折成空格 —— 想看全文就拖表头边界把列拉宽，或双击打开编辑框。

**循环刷出来的记录会自动收起来**：开了「留记录」的循环每响一次就补一条已完成记录，这些记录按来源收成一条可展开的条目（默认合上），免得把列表淹掉。

```
待提醒
  喝水提醒        循环   待提醒     ← 循环便签自己，照常显示
已完成
▸ 喝水提醒        记录   3 条       ← 它刷出来的记录收在这儿
```

- 点展开按钮或双击条目标题即可展开／收起
- 选中条目标题点「删除」= 删掉它名下那堆记录；展开后选中某条删 = 只删那一条
- Ctrl+A 全选会跳过条目标题，合着的条目里的记录照样选得上

底部那行时间**点一下**可以在「北京时间」和「本地时间」之间切换，选过会记住。

## 几点注意

- **错过的提醒不会补弹**：程序没运行时到了点的，只在列表里标红，不会下次启动一股脑弹出来。
- 便签存在 `%APPDATA%\RemindNotes\reminders.json`，每次改动立即落盘；文件坏了会自动改名成 `.bad` 并空着启动，不会崩。
